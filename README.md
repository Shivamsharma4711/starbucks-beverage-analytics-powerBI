# Starbucks Beverage Analytics Dashboard | Power BI

## 📊 Project Overview

The Starbucks Beverage Analytics Dashboard is an interactive Power BI project designed to analyze beverage-level nutritional information and category distribution.

The dashboard provides insights into calories, sugar, caffeine, beverage categories, and Starbucks global presence through interactive visualizations and KPI cards.

The objective of this project is to transform raw beverage data into meaningful business insights using Power BI.

---

## 🎯 Business Objective

The main objective of this project is to analyze Starbucks beverage data and answer questions such as:

- How many beverages are included in the dataset?
- What is the average calorie content of beverages?
- What is the average sugar content?
- Which beverage categories have higher caffeine levels?
- Which beverages have the highest caffeine content?
- How are beverages distributed across different categories?
- What does Starbucks' global presence look like across beverage categories?

---

## 📌 Key KPIs

The dashboard highlights the following key metrics:

- Total Beverages: 33
- Average Sugar: 32.96
- Average Calories: 193.87
- Average Caffeine: 81

These KPIs provide a quick overview of the nutritional characteristics of the beverages analyzed.

---

## 📈 Dashboard Features

### 1. Average Calories by Beverage Category

A category-level visualization showing how average calorie values vary across different beverage categories.

### 2. Starbucks Global Presence

A visual comparison of Starbucks presence across beverage categories.

### 3. Beverage Category Distribution

A donut chart showing the proportion of beverages across different categories.

### 4. Average Caffeine by Category

A horizontal bar chart comparing average caffeine levels across beverage categories.

### 5. Top 5 Highest Caffeine Beverages

A ranking of the five beverages with the highest caffeine content.

---

## 🔍 Key Insights

Some observations from the dashboard include:

- Brewed Coffee has the highest caffeine value among the beverages shown.
- Coffee-related beverages contribute significantly to the overall caffeine profile.
- Beverage categories show noticeable variation in average calorie levels.
- Nutritional characteristics such as calories, sugar, and caffeine vary considerably across beverage categories.
- The dashboard enables quick comparison between individual beverages and broader beverage categories.
